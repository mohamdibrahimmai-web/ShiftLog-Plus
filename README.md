# ShiftLog+

Staff break tracking for restaurant branches. Open `index.html` or publish this folder with GitHub Pages.

Each browser keeps its own staff and break records in local storage. Use Backup and Restore to move a branch's records to another device. Import staff from Excel, CSV, TSV or an image, then review the names before adding them. The End break button turns red after 30 minutes.

For GitHub Pages, create a repository, upload `index.html`, then enable Pages from the main branch and root folder. Opening the page on a different device starts with an empty staff list.
